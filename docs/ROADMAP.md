# 開發及驗收
- 0.1：本機照片讀取、人工家人標籤、GPS 與人工地點、近時照片線索、EmbeddingGemma 2 場景向量與持久索引。先完成編譯和真機測試。
- 0.2：家人自願提供參考照片、專用人臉模型授權與效能驗證；不得用一般語意向量當身分判斷。候選需使用者確認，支援錯誤修正、撤回與刪除。
- 0.3：OCR 招牌、地標候選、影像相似地點、照片日期交叉證據、手動確認、多人及地點交集。無原始 GPS 時始終標示推測。
- 0.4：斷點續掃、權限變更/刪除同步、加密與備份政策、實機基準測試、Android APK、iOS TestFlight。
- 驗收：20 張同一地點有/無 GPS 混合照片；驗證缺 GPS 不被誤寫成真實 GPS。100 張不同家人與多人照片測試標籤及錯誤修正。離線模式測試已下載模型與索引。確認不傳出照片/家人資料。
